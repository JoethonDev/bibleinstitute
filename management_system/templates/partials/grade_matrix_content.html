{% load i18n %} {% comment %} Grades matrix workspace. Presentation only: level tabs, filter parameters, matrix columns/cells, frozen identity column, XLSX link, pagination query and every HTMX hook are preserved. Score tones are derived from the only value the view supplies per cell (`grade` out of `total`): the band is the integer percentage of that pair (80 and above = good, 60-79 = mid, below 60 = bad). A cell whose quiz has no total keeps the plain tone because no percentage exists. The legend below the matrix lists exactly those bands plus the not-submitted dash. Sticky sub-header: `.aw-matrix thead th` is `position: sticky; top: 0`, and this matrix has a two-row header (course groups, then quizzes), so the second row needs the height of the first as its offset. That offset is published by the `aw-th-subhead` class, whose stylesheet rule is scoped to `.aw-table thead th.aw-th-subhead`; it reaches this matrix only when the matrix table is added to that selector (see handoff). No inline offset remains. {% endcomment %}
